# Chrome Text Search Extension

웹 페이지 내에서 실시간 증분 검색(Incremental Search), 텍스트 하이라이트 및 단축키 내비게이션을 제공하는 Chrome 확장 프로그램(Manifest V3)입니다.

---

## 주요 기능

1. **커스텀 검색 바 오버레이**
   - 첨부 UI 디자인과 일치하는 미려한 다크 테마 플로팅 캡슐형 검색 바
   - Shadow DOM을 적용하여 웹 페이지 고유 CSS와의 간섭 및 충돌 방지
   - 검색 바 맨 앞의 `+` 버튼을 통해 **다중 검색 바(Multi-Search Bars)** 추가 및 세로 스택 정렬
   - 각 검색 바마다 고유한 하이라이트 색상(노란색, 청록색, 마젠타, 연두색, 보라색, 주황색 등) 자동 할당
   - 각 검색 바별 개별 독립 탐색, 카운트 표시, 옵션 토글 및 이전/다음 내비게이션
   - 컴팩트한 슬림 레이아웃으로 `MatchCase`, `ByWord`, `RegExp` 체크박스가 한 줄에 잘리지 않고 표시
   - 입력값 즉시 지우기(Clear `✕`) 버튼 및 실시간 일치 건수 표시 (예: `1 of 10`)
   - 3가지 검색 옵션 체크박스 제공:
     - `MatchCase`: 영문 대소문자 정확히 일치
     - `ByWord`: 단어 단위(Boundary `\b`)로 일치
     - `RegExp`: 정규 표현식 기반 유연한 패턴 검색
   - **검색바 상태 자동 기억**: 마지막으로 사용한 검색바 개수 및 각 검색바의 일치 옵션(`MatchCase`, `ByWord`, `RegExp`)을 자동으로 저장하여 다음 재실행 시 그대로 복원

2. **검색 단축키 (Shortcut)**
   - 기본값: `Ctrl + F` (기본 브라우저 검색창 대신 커스텀 검색 바 호출)
   - 옵션(설정) 메뉴에서 사용자가 원하는 단축키로 자유롭게 변경 가능

3. **증분 검색 (Incremental Search) & 하이라이트**
   - 텍스트 입력 즉시 페이지 내 일치 문자열을 탐색하여 실시간 하이라이트 표시
   - 현재 활성화된 일치 항목과 일반 일치 항목을 구분하여 시각화

4. **자동 이동 (Auto-Move)**
   - 검색된 문자열이 1개 이상 존재할 경우, 첫 번째 매칭 위치로 화면을 자동 스크롤
   - 옵션 설정 메뉴에서 활성화/비활성화 (En/Disable) 가능

5. **일치 항목 간 이동 (Navigation)**
   - **다음(아래) 이동**: `Enter` 또는 `F3` (또는 검색 바의 `↓` 버튼)
   - **이전(위) 이동**: `Shift + Enter` 또는 `F4` (또는 검색 바의 `↑` 버튼)
   - **검색창 닫기**: `Escape` (또는 검색 바의 `✕` 버튼)

6. **팝업 내 통합 옵션 설정**
   - 별도 옵션 페이지 없이 툴바 팝업(`popup.html`)에서 모든 설정을 즉시 변경 가능
   - 검색 호출 단축키 변경(키 감지) 및 초기화
   - **기본 검색바 개수 설정**: 초기 기본값 1개 (1~6개 설정 가능)
   - Auto-Move 기능 On/Off 토글 체크박스
   - 1번 검색바 일반 하이라이트 색상 및 활성 색상 커스터마이징 (컬러 피커)
   - 변경 즉시 `chrome.storage.sync`로 저장 및 피드백 안내

## 디렉토리 구조

```text
chrome-extension-search/
├── manifest.json       # Manifest V3 메타데이터, content_scripts 및 권한 설정
├── background.js       # 백그라운드 Service Worker (초기 기본 설정값 세팅)
├── content.js          # 웹 페이지 내 다중 검색 바 UI 생성, 하이라이트 및 이동 로직
├── content.css         # 웹 페이지 내 하이라이트 mark 태그 스타일 정의
├── popup.html          # 브라우저 툴바 팝업 UI (현재 탭 검색창 호출 및 통합 옵션 설정)
├── popup.css           # 팝업 전용 스타일시트
├── popup.js            # 팝업 동작 및 실시간 옵션 저장 스크립트
├── icon16.png          # 16x16 아이콘
├── icon32.png          # 32x32 툴바 고해상도 아이콘
├── icon48.png          # 48x48 아이콘
├── icon128.png         # 128x128 아이콘
└── README.md           # 설명 문서
```

## 설치 및 테스트 방법

1. Chrome 브라우저 주소창에 `chrome://extensions/` 입력 후 접속합니다.
2. 우측 상단의 **개발자 모드(Developer mode)**를 켭니다.
3. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다(Load unpacked)** 버튼을 클릭합니다.
4. `D:\.gradle\OneDrive\_MyCode\chrome-extension-search` 디렉토리를 선택합니다.
5. **툴바에 아이콘 고정**: 브라우저 우측 상단의 **퍼즐 모양(🧩)** 버튼을 누른 뒤 `Search Extension` 옆의 **압정(핀 📌) 아이콘**을 클릭하면 툴바에 항상 표시됩니다.
6. 웹 페이지(예: 일반 뉴스 사이트나 블로그 등)를 연 뒤 `Ctrl + F`를 눌러 검색 바가 정상 작동하는지 확인합니다.
   *(이미 열려있던 탭은 확장 프로그램 로드 후 새로고침(F5)을 해주어야 content script가 주입됩니다)*
7. 브라우저 우측 상단 툴바의 **확장 프로그램 아이콘**을 클릭하면 즉시 검색창을 열거나 단축키, Auto-Move, 하이라이트 색상을 설정할 수 있습니다.
