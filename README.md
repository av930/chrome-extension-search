# Chrome Text Search Extension

웹 페이지 내에서 실시간 증분 검색(Incremental Search), 텍스트 하이라이트 및 단축키 내비게이션을 제공하는 Chrome 확장 프로그램(Manifest V3)입니다.

---

## 주요 기능

1. **커스텀 검색 바 오버레이**
   - 첨부 UI 디자인과 일치하는 미려한 다크 테마 플로팅 캡슐형 검색 바
   - Shadow DOM을 적용하여 웹 페이지 고유 CSS와의 간섭 및 충돌 방지
   - 검색 바 맨 앞의 `+` 버튼을 통해 **다중 검색 바(Multi-Search Bars)** 추가 및 세로 스택 정렬
   - 각 검색 바마다 고유한 하이라이트 색상(노란색, 청록색, 마젠타, 연두색, 보라색, 주황색 등) 자동 할당
   - 각 검색 바별 개별 독립 탐색, 카운트 표시, 옵션 토글 및 이전/다음 내비게이션
   - 컴팩트한 슬림 레이아웃으로 `MatchCase`, `ByWord`, `RegExp` 체크박스가 한 줄에 잘리지 않고 표시
   - 입력값 즉시 지우기(Clear `✕`) 버튼 및 실시간 일치 건수 표시 (예: `1 of 10`)
   - 3가지 검색 옵션 체크박스 제공:
     - `MatchCase`: 영문 대소문자 정확히 일치
     - `ByWord`: 단어 단위(Boundary `\b`)로 일치
     - `RegExp`: 정규 표현식 기반 유연한 패턴 검색
   - **검색바 상태 자동 기억**: 마지막으로 사용한 검색바 개수 및 각 검색바의 일치 옵션(`MatchCase`, `ByWord`, `RegExp`)을 자동으로 저장하여 다음 재실행 시 그대로 복원

2. **검색 단축키 (Shortcut)**
   - 기본값: `Ctrl + F` (기본 브라우저 검색창 대신 커스텀 검색 바 호출)
   - 옵션(설정) 메뉴에서 사용자가 원하는 단축키로 자유롭게 변경 가능

3. **초고속 증분 검색 (Incremental Search) & 고성능 하이라이트**
   - 텍스트 입력 즉시 페이지 내 일치 문자열을 탐색하여 실시간 하이라이트 표시
   - 현재 활성화된 일치 항목과 일반 일치 항목을 구분하여 시각화
   - **엔진 레벨 성능 최적화 적용**:
     - **고속 타이핑 디바운스(80ms)**: 연속 입력 시 불필요한 전체 DOM 재탐색 낭비를 방지하여 렉 없는 부드러운 타이핑 보장
     - **DOM 복원 최적화 (Set 기반 normalize)**: 하이라이트 해제 시 부모 노드별 중복 `normalize()` 호출을 제거하여 수백~수천 개 매칭에서도 즉각적인 반응성 확보
     - **C++ 기반 고속 사전 필터링**: 일반 텍스트 검색 시 V8 엔진 네이티브 `includes`/`indexOf`로 비매칭 텍스트 노드를 빠르게 통과
     - **불필요한 비텍스트 태그 필터링**: `SVG`/`MathML` 네임스페이스와 `CANVAS`, `AUDIO`, `VIDEO`, `TEMPLATE`, `OPTION` 등을 TreeWalker 순회에서 제외
     - **지연 가시성 검사**: 비용이 큰 `checkVisibility()` 판정을 텍스트 매칭에 성공한 노드에 한해서만 수행하고 엘리먼트별로 캐싱
     - **대량 매칭 보호 한도(1,500+)**: 한 글자 검색 등 과도한 매칭 발생 시 브라우저 탭 프리징 및 메모리 폭발 방지
     - **스토리지 쓰기 쿼터 보호(400ms 디바운스)**: Chrome Storage Sync의 분당 120회 쓰기 한도 초과 오류 방지

4. **다양한 웹 콘텐츠 호환 검색 (Wide Content Coverage)**
   - **Shadow DOM(Web Components) 탐색**: 일반 `TreeWalker`로는 접근 불가한 open 모드 Shadow Root 내부까지 재귀 순회하여, 커스텀 엘리먼트 기반의 최신 웹앱 텍스트도 정상 검색
   - **동일 출처 iframe 탐색**: 페이지에 포함된 same-origin `<iframe>`/`<frame>` 문서 내부 텍스트까지 검색 및 하이라이트 (최대 12단계 중첩)
   - **동적 콘텐츠 자동 재검색**: `MutationObserver`로 SPA 라우팅, 무한 스크롤, AJAX 지연 로딩으로 새로 추가된 텍스트를 감지해 400ms 디바운스 후 현재 검색어를 자동 재적용
   - **숨김 텍스트 제외**: `display:none` / `visibility:hidden` 영역의 텍스트는 이동이 불가능하므로 일치 건수에서 제외하여 카운트 정확도 확보
   - **접힌 `<details>` 자동 펼침**: 접혀 있는 아코디언 내부의 일치 항목으로 이동 시 상위 `<details>` 요소를 자동으로 열어 화면에 노출

   > **검색 제한 사항 (브라우저 보안/기술 제약)**
   > - **교차 출처(cross-origin) iframe**: 브라우저 동일 출처 정책상 문서 접근이 차단되어 검색 불가
   > - **closed 모드 Shadow DOM**: 스펙상 외부 스크립트 접근이 원천 차단되어 검색 불가
   > - **Chrome 내장 PDF 뷰어**: 플러그인 기반 렌더링으로 콘텐츠 스크립트가 접근 불가 (PDF는 브라우저 기본 `Ctrl+F` 사용 권장)
   > - **`<input>` / `<textarea>` 입력값**: 폼 입력값은 `<mark>` 래핑이 불가능하여 검색 대상에서 제외
   > - **`contenteditable` 편집 영역**: 사용자의 편집 내용 손상을 방지하기 위해 의도적으로 제외
   > - **`<canvas>` / 이미지 내 텍스트**: 텍스트 노드가 아닌 픽셀 데이터이므로 검색 불가
   > - `chrome://`, Chrome 웹 스토어 등 브라우저 보호 페이지에서는 확장 프로그램 주입 자체가 차단됨

5. **자동 이동 (Auto-Move)**
   - 검색된 문자열이 1개 이상 존재할 경우, 첫 번째 매칭 위치로 화면을 자동 스크롤
   - 옵션 설정 메뉴에서 활성화/비활성화 (En/Disable) 가능

6. **일치 항목 간 이동 (Navigation)**
   - **다음(아래) 이동**: `Enter` 또는 `F3` (또는 검색 바의 `↓` 버튼)
   - **이전(위) 이동**: `Shift + Enter` 또는 `F4` (또는 검색 바의 `↑` 버튼)
   - **검색창 닫기**: `Escape` (또는 검색 바의 `✕` 버튼)

7. **상단 공통 바 (Common Bar) & 텍스트 선택/복사/확장**
   - **텍스트 클립보드 복사 (`text select`)**: 현재 웹페이지에서 선택(드래그)된 텍스트(또는 활성 검색 일치 항목)를 원클릭으로 클립보드에 복사 (`Copied!` 피드백 제공)
   - **좌/우 1단어 및 3단어 선택 확장 (`<<<`, `<`, `>`, `>>>`)**:
     - `<<<` 버튼 클릭 시: 현재 선택된 텍스트의 왼쪽 경계를 **3단어** 단위로 고속 확장
     - `<` 버튼 클릭 시: 현재 선택된 텍스트의 왼쪽 경계를 **1단어** 단위로 확장
     - `>` 버튼 클릭 시: 현재 선택된 텍스트의 오른쪽 경계를 **1단어** 단위로 확장
     - `>>>` 버튼 클릭 시: 현재 선택된 텍스트의 오른쪽 경계를 **3단어** 단위로 고속 확장
     - **선택기능 무시구분자 지원**: 옵션에 지정된 문자(기본값: `-`)는 단어 구분자로 취급하지 않고 하나의 단어로 연결하여 확장 (예: `im-him`을 1단어로 처리)
     - 선택 범위가 확장되어도 기존 검색바의 검색어는 변경되지 않고 그대로 유지
   - **북마크 핀 (Pin to bookmarks)**: 각 검색바 우측의 핀 버튼 클릭 시 현재 페이지 URL과 검색 키워드를 저장하며, 상단 바의 오른쪽부터 왼쪽 순으로 랜덤 컬러 핀 클립 생성. 클립 클릭 시 해당 페이지로 이동 및 검색어 자동 주입 실행, `✕` 버튼으로 삭제 가능

8. **팝업 내 통합 옵션 설정**
   - 별도 옵션 페이지 없이 툴바 팝업(`popup.html`)에서 모든 설정을 즉시 변경 가능
   - 검색 호출 단축키 변경(키 감지) 및 초기화
   - **기본 검색바 개수 설정**: 초기 기본값 2개 (1~6개 설정 가능)
   - Auto-Move 기능 On/Off 토글 체크박스
   - **선택기능 무시구분자 설정**: 기본값 `-` (단어 확장 시 구분자로 취급하지 않을 문자 목록 자유 설정)
   - 1번 검색바 일반 하이라이트 색상 및 활성 색상 커스터마이징 (컬러 피커)
   - **개발자 후원 및 피드백**: 팝업 내 `Donate & feedback : av9300@gmail.com` 안내 배치
   - 변경 즉시 `chrome.storage.sync`로 저장 및 피드백 안내

## 디렉토리 구조

```text
chrome-extension-search/
├── manifest.json       # Manifest V3 메타데이터, content_scripts 및 권한 설정
├── background.js       # 백그라운드 Service Worker (초기 기본 설정값 세팅)
├── content.js          # 웹 페이지 내 다중 검색 바 UI 생성, 하이라이트 및 이동 로직
├── content.css         # 웹 페이지 내 하이라이트 mark 태그 스타일 정의
├── popup.html          # 브라우저 툴바 팝업 UI (현재 탭 검색창 호출 및 통합 옵션 설정)
├── popup.css           # 팝업 전용 스타일시트
├── popup.js            # 팝업 동작 및 실시간 옵션 저장 스크립트
├── icon16.png          # 16x16 아이콘
├── icon32.png          # 32x32 툴바 고해상도 아이콘
├── icon48.png          # 48x48 아이콘
├── icon128.png         # 128x128 아이콘
└── README.md           # 설명 문서
```

## 설치 및 테스트 방법

1. Chrome 브라우저 주소창에 `chrome://extensions/` 입력 후 접속합니다.
2. 우측 상단의 **개발자 모드(Developer mode)**를 켭니다.
3. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다(Load unpacked)** 버튼을 클릭합니다.
4. `D:\.gradle\OneDrive\_MyCode\chrome-extension-search` 디렉토리를 선택합니다.
5. **툴바에 아이콘 고정**: 브라우저 우측 상단의 **퍼즐 모양(🧩)** 버튼을 누른 뒤 `Search Extension` 옆의 **압정(핀 📌) 아이콘**을 클릭하면 툴바에 항상 표시됩니다.
6. 웹 페이지(예: 일반 뉴스 사이트나 블로그 등)를 연 뒤 `Ctrl + F`를 눌러 검색 바가 정상 작동하는지 확인합니다.
   *(이미 열려있던 탭은 확장 프로그램 로드 후 새로고침(F5)을 해주어야 content script가 주입됩니다)*
7. 브라우저 우측 상단 툴바의 **확장 프로그램 아이콘**을 클릭하면 즉시 검색창을 열거나 단축키, Auto-Move, 하이라이트 색상을 설정할 수 있습니다.
